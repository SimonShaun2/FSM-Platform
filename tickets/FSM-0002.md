## Objective
Install the V2 governance set and explicitly retire every conflicting legacy instruction so
exactly one authoritative operating model exists in the repository.

## Product context
Master directive §51 requires this. The repository currently states there are four agents
while the directive defines fifteen team members; it names a retired product boundary; it
describes a Phase 1A–3 roadmap superseded by Sprint 0–22; and `CODEX.md` mandates an
Agent 4 approval gate that no longer exists. Contradictory instructions are worse than
missing ones because they are followed confidently. See `PROJECT_STATE.md` BD-004, BD-006.

## User story
As any team member reading the repository cold, I need exactly one description of how this
project operates, so that I never have to guess which of two conflicting files is current.

## Scope
Install the V2 governance files. Audit every existing document for statements contradicting
the master directive. Retire obsolete content explicitly rather than deleting it silently.
Retain sound engineering principles.

## Deliverables
1. `AGENTS.md` v2.0 installed (supplied).
2. `CODEX.md` v2.0 installed (supplied).
3. `TEAM.md` installed (supplied).
4. `PROJECT_STATE.md` installed (supplied).
5. `SPRINT_ROADMAP.md` installed (supplied).
6. `GITHUB_WORKFLOW.md` installed (supplied).
7. `MASTER_PRODUCT_SPEC.md` — the V2 directive committed verbatim as the controlling document.
8. `docs/legacy/` — prior `AGENTS.md`, `CODEX.md`, `WORKFLOW.md`, `docs/planning/*` moved here,
   each prefixed with a `> RETIRED — superseded by <file> on <date>. Historical reference only.` banner.
9. `docs/audit/GOVERNANCE-CONFLICTS.md` — every contradiction found, its resolution, and the file it now lives in.
10. `README.md` rewritten as the repository entry point with the correct reading order.

## Acceptance criteria
- [ ] No non-retired file in the repository references Agent 1, Agent 2, Agent 3 or Agent 4 as an operating role
- [ ] No non-retired file states "thinner system, smarter brain" as the governing product boundary
- [ ] No non-retired file presents Phase 1A/1B/1C/2/3 as the active roadmap
- [ ] No non-retired file describes `/packages/ui`, which does not exist
- [ ] Every file reference to the schema points at `packages/db/src/schema.ts`
- [ ] Every retired document carries the retirement banner and lives under `docs/legacy/`
- [ ] The eleven engineering principles are preserved in `AGENTS.md` §5
- [ ] `README.md` names the reading order: `AGENTS.md` → `TEAM.md` → `PROJECT_STATE.md` → `SPRINT_ROADMAP.md` → ticket → `CODEX.md`
- [ ] A grep for retired terminology across non-legacy paths returns zero operative hits

## Required tests
Automated governance-consistency check added to CI under FSM-0010: greps for retired
terminology outside `docs/legacy/` and fails the build on an operative hit.

## Impact
**API / Database / Frontend / Mobile / Integration:** none. Documentation only.

## Security considerations
`SECURITY.md` is authored in Sprint 1. This ticket must not leave security guidance in a
retired file with no live replacement — carry forward any operative security rule into
`AGENTS.md` §10.

## Tenant isolation considerations
Preserve the tenant-scoping rules from the legacy documents into `AGENTS.md` §8 and
`CODEX.md` §4. Losing them in the rewrite would be a serious regression.

## Observability requirements
None.

## Migration requirements
None.

## Rollback considerations
Legacy files are moved, never deleted. Full recovery via git history.

## Non-goals
Not authoring the remaining Sprint 1 specification set (`ARCHITECTURE.md`, `PAYMENTS.md`,
`UX_SYSTEM.md`, etc.) — those are separate deliverables. Not changing code.

## Required review
TL-01 implements · Claude reviews for product-statement accuracy · DES-01 confirms UX
principles in `AGENTS.md` §3 are correctly stated.

## Required QA
QA-01 runs the terminology grep and verifies every retired file is bannered and relocated.

## Completion procedure
Merge → update `PROJECT_STATE.md` §5 and §7 → update `CHANGELOG.md` → announce the new
reading order to all owners.
